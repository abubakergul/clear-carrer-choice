# Result Page

## Overview

The result page is shown after signup. It displays the user's initial Fit Insight — generated by the AI based on their conversation. This must feel personal and meaningful, not generic.

## Route

`/result`
Protected — redirect to `/login` if no session.

## How the Fit Insight is Generated

After the conversation ends and the user signs up:
1. Send the full conversation transcript to OpenAI with a separate "analysis" prompt
2. The AI returns a structured JSON response with:
   - A 1–2 sentence pattern summary (what the user tends to enjoy, avoid, value)
   - 2–3 career areas that match the pattern
3. Save this to the `FitInsight` model in the database
4. Render it on the result page

## Analysis Prompt

Store in `src/lib/prompts/analysis.ts`

```
You are analysing a career guidance conversation with a student.
Based on the conversation, identify the student's patterns.

Return ONLY a JSON object with this exact structure — no markdown, no explanation:
{
  "summary": "One or two sentences describing what the student tends to enjoy, avoid, and value.",
  "areas": ["Career Area 1", "Career Area 2", "Career Area 3"]
}

Rules:
- The summary must feel personal, not generic. Reference specific things from the conversation.
- The areas must be realistic fields of study or career paths, not vague categories.
- Maximum 3 areas.
- Never say "you should be X". Describe patterns only.
```

## UI Content

**Section 1 — The Fit Insight**
Heading: "Here's what I'm starting to see about you:"
Body: Display the `summary` from FitInsight

**Section 2 — Your Match Areas**
Heading: "Fields that tend to fit this pattern:"
Body: List the `areas` as clean cards or pills

**Section 3 — Disclaimer (always visible)**
"This is based on your conversation — use it as a starting point, not a final answer. Big decisions deserve reflection and real conversations too."

**Section 4 — CTA to Dashboard**
"Ready to explore further?"
Button: "Start Exploring" → `/dashboard`

## What NOT to Include

- No percentage scores — they feel like homework grades
- No ranked lists
- No "you are a [type]" framing
- No links to external career sites
