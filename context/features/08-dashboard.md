# Dashboard

## Overview

The user's home base after signup. Dead simple — three things only. No complexity, no analytics, no graphs.

## Route

`/dashboard`
Protected — redirect to `/login` if no session.

## Layout (3 sections only)

### Section 1 — Current Exploration
Shows the user's current fit insight areas.
Label: "You're currently exploring:"
Content: Display the `areas` from FitInsight as readable text
e.g. "UX Design and Architecture"

### Section 2 — Today's Task
Shows the current day's micro-task.
Label: "Today's task (15 min):"
Content: The task description for today's day number
Below the task: Three feedback buttons (shown after the user reads it):
- ✅ Interesting
- 😕 Not sure
- ❌ Not for me

Feedback is submitted via Server Action and saves to `TaskEntry.feedback`
After feedback is given, the button area changes to: "See you tomorrow ✓"

### Section 3 — Re-evaluate Option
A subtle link or button at the bottom:
"Not feeling this direction? Re-explore from the start"
→ Goes back to `/chat` and starts a new conversation (creates a new Conversation record)

## Task Generation Logic

- Tasks are pre-generated when the FitInsight is first created (Day 1–7)
- They are generated by the AI based on the `areas` in the FitInsight
- Stored in the `TaskEntry` model with `day` field (1–7)
- Dashboard reads the task for today's day number based on account age (Day 1 = day of signup, Day 2 = next day, etc.)
- If the user is past Day 7, show: "You've completed your first exploration cycle. Want to go deeper?" with a CTA to re-explore

## Task Generation Prompt

Store in `src/lib/prompts/tasks.ts`

```
You are generating 7 daily micro-tasks to help a student explore a career area.
Each task must take 15 minutes or less. Do not include links.
Describe what to search or do clearly enough that the student doesn't need to think about where to start.

Career areas: {areas}

Return ONLY a JSON array of 7 strings — no markdown, no explanation:
["Task for day 1", "Task for day 2", ..., "Task for day 7"]

Rules:
- Each task must be specific and actionable (e.g. "Search YouTube: 'day in the life UX designer' — watch any one video")
- Tasks should get progressively deeper over 7 days
- No links, no URLs — describe what to search instead
- Do not use the word "research" — be specific about what exactly to do
```

## What NOT to Build

- No progress bars or completion percentages
- No streak tracking
- No notifications
- No analytics
- No graphs
