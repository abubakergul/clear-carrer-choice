# 16-home-screen-spec.md

# Home Screen

## Overview

The home screen is NOT a productivity dashboard.

It is:

- a calm continuation screen
- a lightweight exploration hub
- a reflection-aware discovery space

Primary emotional goal:

> help users continue exploring without overwhelm.

The screen should feel:

- calm
- lightweight
- emotionally safe
- non-judgmental

Avoid productivity-app energy.

---

# Route

```text
/home
```

Protected route.

---

# Primary Product Loop

The home screen should reinforce:

```text
explore
→ notice reaction
→ reflect
→ gain clarity
→ continue
```

The screen exists to gently continue this loop.

---

# Home Screen Priorities

Priority order:

1. Active exploration
2. Lightweight insight awareness
3. Reflection continuity
4. Discovery history

The screen should NOT prioritize:

- productivity
- completion tracking
- metrics
- streaks
- progress gamification

---

# Layout Structure

## Section 1 — Current Direction

Purpose:

- provide lightweight orientation
- reinforce evolving self-discovery
- avoid definitive identity labeling

Display:

- FitInsight summary
- current directions
- optional evolving tension

This section should feel:

- lightweight
- evolving
- non-definitive

Example tone:

> “You seem repeatedly drawn toward collaborative creative problem-solving.”

Avoid:

> “You are a UX Designer.”

---

# Section 2 — Active Exploration

Main focus of the screen.

Display:

- exploration title
- exploration prompt
- estimated duration
- optional “Why this exploration?” context

Primary CTA:

```text
Start Exploration
```

Secondary actions:

```text
Skip
Already know this about myself
```

Avoid:

- “Complete Task”
- “Finish Assignment”
- “Challenge”

---

# Exploration Context

Optionally show lightweight AI reasoning.

Example:

> “Generated because you showed curiosity around analytical collaboration.”

Purpose:

- improve trust
- increase personalization clarity
- reduce randomness feeling

This explanation should remain:

- short
- calm
- non-technical

---

# Section 3 — Reflection Continuity

Optional lightweight section.

Purpose:

- reinforce self-awareness
- encourage pattern recognition

Examples:

> “You often feel energized during creative observation-based explorations.”

OR:

> “You seem curious about collaborative environments but hesitant about technical implementation.”

Avoid:

- charts
- percentages
- dashboards
- scores

Insights should feel human and reflective.

---

# Section 4 — Discovery Timeline

History should feel like:

> a personal discovery timeline

NOT:

> a task archive

Display lightweight history entries such as:

- exploration title
- selected emotional signals
- date

Purpose:

- help users notice patterns over time
- reinforce gradual clarity

---

# Empty States

## No Active Exploration

Possible causes:

- generation delay
- cooldown
- recent completion

Display calm messaging.

Example:

> “We’re preparing your next exploration.”

Avoid:

- error energy
- productivity urgency

---

# Loading States

Loading should feel:

- lightweight
- calm
- intentional

Avoid:

- aggressive spinners
- excessive skeleton complexity

---

# Visual Tone

The home screen should feel:

- spacious
- calm
- emotionally safe
- curiosity-oriented

Avoid:

- crowded dashboards
- gamification
- productivity aesthetics
- excessive KPI displays

---

# Language Rules

Avoid words like:

- task
- mission
- assignment
- productivity
- achievement
- performance

Prefer words like:

- exploration
- notice
- curiosity
- reflection
- discover

---

# Mobile-First Behavior

The home screen should optimize for:

- quick continuation
- low cognitive load
- immediate exploration access

Primary exploration CTA should remain highly accessible on mobile.

---

The home screen exists to:

> gently guide users through repeated self-discovery experiences.
