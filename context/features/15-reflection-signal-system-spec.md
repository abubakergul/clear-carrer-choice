# Reflection + Signal Interpretation

## Overview

After each exploration, the user submits a lightweight reflection.

The goal is:
- emotional signal collection
- behavioral pattern detection

NOT:
- journaling
- productivity tracking

---

# Reflection Structure

Users can select MULTIPLE reactions.

Example:
- I became curious quickly
- I felt intimidated
- I wanted to continue
- I lost interest fast

---

# Reflection Rules

Reflections should:
- take under 10 seconds
- feel emotionally intuitive
- avoid long typing

Structured reactions are preferred over free text.

---

# Signal Categories

Examples:
- curiosity
- intimidation
- boredom
- excitement
- confusion
- desire for structure
- desire for creativity
- resistance
- engagement
